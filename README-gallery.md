# মহামায়া AI — গ্যালারি সেটআপ

## চালানোর নিয়ম (Node.js 18+ লাগবে, কোনো `npm install` নেই)

    ADMIN_PASSWORD="আপনার-শক্ত-পাসওয়ার্ড" node server.js

- সাইট: http://localhost:3000
- অ্যাডমিন প্যানেল: http://localhost:3000/admin
- পাসওয়ার্ড কমপক্ষে ১০ অক্ষরের না হলে সার্ভার চালুই হবে না।
- পাসওয়ার্ড কোডে লিখবেন না, শুধু environment variable-এ রাখুন।

## কীভাবে কাজ করে
1. ব্যবহারকারী চ্যাটে "🖼️ গ্যালারি" → "📤 ছবি পাঠান" দিয়ে ছবি জমা দেয়।
2. ছবি `pending` অবস্থায় থাকে। পাবলিক API বা URL দিয়ে তা কেউ দেখতে পায় না।
3. অ্যাডমিন `/admin`-এ লগইন করে ✅ অনুমোদন দিলে তবেই গ্যালারিতে দেখায়।
   "লুকান" দিলে আবার অপেক্ষমাণ হয়, "মুছুন" দিলে ফাইলসহ মুছে যায়।

## নিরাপত্তা ব্যবস্থা
- অ্যাডমিন লগইন: HttpOnly + SameSite=Strict কুকি, ৮ ঘণ্টার সেশন, ৫ বার ভুল হলে ১৫ মিনিট লক।
- অ্যাডমিন POST-এ CSRF সুরক্ষা (কাস্টম হেডার + একই-origin যাচাই)।
- আপলোড: শুধু JPEG (ম্যাজিক বাইট যাচাই), সর্বোচ্চ ৩ MB, প্রতি IP-তে ঘণ্টায় ৫টি, অপেক্ষমাণ ২০০টির বেশি নয়।
- ব্রাউজার ছবি ছোট করে JPEG বানিয়ে পাঠায়, তাই EXIF/GPS লোকেশন বাদ পড়ে।
- ফাইলের নাম এলোমেলো (অনুমান করা যায় না); ছবি `nosniff` + sandbox CSP সহ দেওয়া হয়।
- ক্যাপশন সবসময় `textContent` দিয়ে দেখানো হয়, তাই HTML/স্ক্রিপ্ট ঢোকানো যায় না।
- `data/`, `server.js` ইত্যাদি কখনও ওয়েবে দেওয়া হয় না (শুধু তালিকাভুক্ত ফাইল)।

## অনলাইনে দিলে (Render / Railway / VPS)
- এই সাইটে ব্যাকএন্ড লাগে, তাই GitHub Pages/Netlify-র মতো শুধু-স্ট্যাটিক হোস্টিংয়ে গ্যালারি চলবে না।
- এনভায়রনমেন্ট ভ্যারিয়েবল: `ADMIN_PASSWORD`, `NODE_ENV=production`, আর প্রক্সির পেছনে থাকলে `TRUST_PROXY=1`।
- HTTPS অবশ্যই চালু রাখুন (production-এ কুকি `Secure` হয়ে যায়)।
- ছবি থাকে `data/` ফোল্ডারে। হোস্টিংয়ে স্থায়ী ডিস্ক না থাকলে `DATA_DIR` একটি persistent volume-এ দিন, নইলে রিস্টার্টে ছবি হারাবে।
- ফ্রন্টএন্ড আলাদা জায়গায় রাখলে `index.html`-এ `window.GALLERY_API="https://আপনার-সার্ভার"` সেট করতে হবে এবং সার্ভারে CORS লাগবে; সবচেয়ে সহজ হলো সার্ভার থেকেই পুরো সাইট দেওয়া (যেমন এখন)।
